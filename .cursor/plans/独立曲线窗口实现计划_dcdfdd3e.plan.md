# 独立曲线窗口实现计划（修订版）

## 目标

- 取消主窗口中的曲线 Tab，在标题栏右侧图标最左边添加曲线图标
- 点击曲线图标打开独立曲线窗口
- **数据与 UI 解耦**：曲线窗口关闭或未打开时，后台仍接收并缓存 `LinePlotAdd` 数据
- **渲染与 UI 解耦**：采用「后台线程渲染 + UI 线程显示」方案

---

## 一、架构设计

### 1.1 三层模型

```
┌─────────────────────────────────────────────────────────────────┐
│  主线程（Lua 脚本、apiAddPoint）                                   │
│  LinePlotAdd 事件触发  ──────────────────────────────────────────┐
└─────────────────────────────────────────────────────────────────┘  │
                                                                     │
┌──────────────────────────────────────────────────────────────────┘
│  数据接收层（常驻后台线程 / 后台任务）                               │
│  - 订阅 LinePlotAdd，接收 (N, Line)                                │
│  - 写入共享数据结构（如 DataStreamer 或 RingBuffer）                 │
│  - 无论曲线窗口是否打开，始终运行                                   │
└──────────────────────────────┬───────────────────────────────────┘
                               │
┌──────────────────────────────▼───────────────────────────────────┐
│  曲线窗口（打开时）：                                              │
│  - 后台渲染线程：从共享数据读取 → Plot.Render() → 生成位图            │
│  - UI 线程：将位图显示到 Image 控件                                 │
└───────────────────────────────────────────────────────────────────┘
```

### 1.2 数据流

- **LinePlotAdd**：在主线程或 Lua 调用线程触发
- **数据接收**：由常驻后台组件订阅 `LinePlotAdd`，将点写入线程安全的缓冲区（如 `ConcurrentQueue` 或带锁的 DataStreamer 副本）
- **窗口关闭时**：数据接收层继续写入；缓冲区可设上限（如 500 点 × 10 条线），超出则丢弃或覆盖 oldest
- **窗口打开时**：渲染层从缓冲区读取并绘制；可选择「显示历史缓冲」或「仅显示打开后新数据」

---

## 二、数据接收层（常驻）

### 2.1 职责

- 订阅 `LuaEnv.LuaApis.LinePlotAdd`
- 将 `(N, Line)` 写入共享缓冲区
- 在应用启动时即初始化，不依赖曲线窗口是否存在

### 2.2 实现方式

- **方案 A**：使用 10 个 `ConcurrentQueue<double>` 或 `List<double>` + lock，每条线一个
- **方案 B**：使用与 PlotPage 当前相同的 DataStreamer 逻辑，但放在独立类（如 `PlotDataReceiver`）中，不依赖 WPF
- **注意**：ScottPlot 的 DataStreamer 可能依赖 UI 上下文，需确认；若不兼容，则用纯数据结构（如 `List` + lock）作为缓冲，窗口打开时再同步到 DataStreamer

### 2.3 缓冲区设计

- 每条线最多保留 N 个点（如 500）
- 超出时覆盖最旧点（Ring Buffer 语义）
- 线程安全：`AddPoint` 与渲染层读取需加锁或使用无锁结构

---

## 三、曲线窗口：后台渲染 + UI 显示

### 3.1 方案说明

- **后台线程**：从共享缓冲区读取数据 → 更新 Plot 模型 → 调用 `Plot.Render()` 得到位图
- **UI 线程**：将渲染好的位图设为 `Image.Source` 或 `WriteableBitmap`

### 3.2 实现要点

- 使用 `Plot.Render()` 或类似 API 在后台生成 `SKBitmap` / `Bitmap`
- 双缓冲：后台渲染到 Buffer A，完成后与当前显示的 Buffer B 交换；UI 线程只做引用交换
- 刷新频率：由后台线程的定时器控制（如每 50–100ms 渲染一帧）
- 十字光标：可在渲染时一并绘制，或单独在 UI 线程叠加（需坐标转换）

### 3.3 窗口与数据源的关系

- 窗口打开：创建渲染线程，从 `PlotDataReceiver` 读取数据并渲染
- 窗口关闭：停止渲染线程，**不**停止 `PlotDataReceiver`；数据持续累积
- 窗口再次打开：可继续从缓冲区读取（含之前缓存的数据），或清空后仅显示新数据（可选）

## 四、UI 变更（与初版一致）

### 4.1 移除曲线 Tab

- 删除 `MainWindow.xaml` 中曲线 TabItem 及 `PlotFrame`
- 删除 `MainWindow.xaml.cs` 中 `PlotFrame.Navigate(...)` 及相关逻辑

### 4.2 添加曲线图标按钮

- 在标题栏 `StackPanel` 最左侧（LanguageButton 之前）添加 `PlotWindowButton`
- 使用 `fa:FontAwesome Icon="ChartLine"`
- 点击：若窗口未打开则创建并显示；若已打开则 `Activate()`

---

## 五、文件与模块划分


| 模块   | 文件                            | 职责                                      |
| ---- | ----------------------------- | --------------------------------------- |
| 数据接收 | `PlotDataReceiver.cs`（新建）     | 订阅 LinePlotAdd，维护 10 条线的环形缓冲，线程安全       |
| 曲线窗口 | `PlotWindow.xaml` / `.cs`（新建） | 窗口 UI，后台渲染线程，双缓冲位图显示                    |
| 主窗口  | `MainWindow.xaml` / `.cs`     | 移除曲线 Tab，添加曲线按钮，启动时初始化 PlotDataReceiver |


### 初始化时机

- 在 `MainWindow.Window_Loaded` 或 `App.Startup` 中创建 `PlotDataReceiver` 并订阅 `LinePlotAdd`
- 不依赖曲线窗口的创建

---

## 六、ScottPlot 后台渲染可行性

- 需确认 ScottPlot 5 的 `Plot.Render()` 是否可在非 UI 线程调用
- 若必须依附 UI 线程，可退化为：渲染仍在曲线窗口的 Dispatcher 线程执行，但使用 `Dispatcher.BeginInvoke` 低优先级，减轻主窗口压力；数据接收层仍可常驻后台

---

## 七、实现顺序建议

1. 新建 `PlotDataReceiver`，实现 LinePlotAdd 订阅与环形缓冲，在 MainWindow 启动时初始化
2. 新建 PlotWindow，先实现「同线程渲染 + 直接显示」（沿用当前 PlotPage 逻辑），验证从 PlotDataReceiver 读取数据
3. 将 PlotWindow 改为「后台渲染 + 双缓冲 + UI 显示」
4. 移除曲线 Tab，添加曲线按钮，实现点击打开/激活
5. 验证：关闭曲线窗口后持续调用 apiAddPoint，再打开窗口能看到之前缓存的数据（或按策略清空）
